# Weekly Spending Tracker

1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Go to the **Actions** tab -> "Build Android APK" runs automatically (or click "Run workflow").
3. When it's green, open the run and download **weekly-spending-apk** under *Artifacts*.
4. Unzip it and install `app-debug.apk` on your phone (allow "install unknown apps").
